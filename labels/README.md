# labels/

Manual review labels for top-ranked outlier cells.

**License: CC BY-NC-SA 4.0** ([LICENSE](LICENSE)). Labels describe images from the Glimpse battery
CT dataset (Condon et al., Data in Brief 55 (2024) 110614, https://doi.org/10.1016/j.dib.2024.110614;
dataset https://doi.org/10.25452/figshare.plus.25330501). Non-commercial use only. See
[`../DATA_LICENSES.md`](../DATA_LICENSES.md).

Planned taxonomy: `real_defect`, `benign_variation`, `scan_artifact`, `unsure`, with reviewer,
date and reason recorded for every label.
